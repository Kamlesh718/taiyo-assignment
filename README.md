# Contacts & Dashboard App

A responsive React application to manage contacts and visualize global COVID-19 statistics.  

- **Contacts Management:** Add, edit, view, and delete contacts with status, email, and phone.  
- **Global Dashboard:** Shows worldwide COVID-19 statistics, trends over time, and an interactive map.  
- **Responsive Design:**  
  - Desktop: Sidebar navigation  
  - Mobile: Bottom navigation like Instagram  
- **Technologies:** React, Redux Toolkit, React Router, Tailwind CSS, Chart.js, React Leaflet

## Features

### Contacts

- Add new contacts with name, email, phone, and status.
- Edit existing contacts.
- Delete contacts with confirmation.
- View contact details.
- Form validation (phone must be 10 digits, required fields, etc.)

### Dashboard

- **Global Stats:** Total cases, recovered, deaths, active.  
- **Line Chart:** Trends of cases over time.  
- **Interactive Map:** Country-wise data with popups.  

### Navigation

- **Desktop:** Collapsible sidebar with icons and labels.  
- **Mobile:** Fixed bottom navbar with icons, full clickable area.  

---

## Tech Stack

- **Frontend:** React, TypeScript  
- **State Management:** Redux Toolkit
- **Data Fetching:** TanStack Query (React Query) 
- **Routing:** React Router Dom
- **Styling:** Tailwind CSS  
- **Charts:** Chart.js, react-chartjs-2  
- **Maps:** Leaflet, react-leaflet  
- **Icons:** react-icons
